## 这些提示词的共同骨架

```
1. 技术约束     代码生成，禁 Blender / 禁现成模型文件
2. 相机         第三视角，可拖拽 / 旋转 / 缩放
3. UI           零 UI
4. 底座         完整正方形，所有元素在其上
5. 风格         三渲二 + 清晰轮廓线 + 色阶化光照
6. 主体         一个明确视觉中心，其余元素围绕它
7. 清单         8–12 项周边元素（越具体越好）
8. 光比         暖内 / 冷外，或暖点光 / 冷环境
9. 动效         5–8 项循环动画
10. 情绪        一句话定调（这条最影响最终质感）
11. 不要人物
```

## 使用建议

- **直接复制**：每个文件里第一个 ``` 代码块就是完整可投喂的提示词。
- **想要不同结果**：优先改「情绪」那一句和「光比」方案，比改元素清单有效得多。
- **想批量生成**：用 08 的模板 A，从模块库里各挑几项填进去。
- **想要更"高级"的质感**：在美术风格那句后面加「参考 {{ 具体动画/电影 }} 的调色」。

## 与实现代码的关系

01 号提示词已经在本仓库落地（`src/` 下的 Three.js 实现）。其余提示词沿用完全相同的技术要求，因此可以直接复用本项目的：

- `src/core/toon.js` — 三渲二材质与色阶
- `src/core/pipeline.js` — 描边 + 泛光 + 调色
- `src/world/wet.js` — 湿地面平面反射
- `src/world/effects.js` — GPU 粒子天气系统

换场景时主要改 `src/world/` 下的建模文件即可。
