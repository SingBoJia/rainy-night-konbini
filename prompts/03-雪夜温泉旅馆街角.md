# 03 — 雪夜温泉旅馆街角

```
新建一个文件夹，用代码（Three.js / WebGL，不准使用 Blender、不准用现成模型文件）制作一个雪夜温泉旅馆街角小场景。

以第三视角观察，可自由拖拽、旋转、缩放的微缩三维模型 / 小型景观，无任何 UI 界面元素。正方形底座，所有元素搭建其上，构图紧凑、层次清晰，小巧精致的收藏级模型感。

风格：三渲二，日式二次元动画氛围，干净材质、明确轮廓、柔和但富有层次感。

场景主体：一条积雪的石板坡道从底座前方缓缓上升，坡道尽头是一家传统木造温泉旅馆。旅馆正门挂着红白暖帘和纸灯笼，木格栅门半开，门内透出温暖的橙光，能看到玄关的鞋柜和一截红色地毯。屋檐下垂着冰凌，屋檐积雪厚厚一层，屋瓦是深灰色的。

旅馆左侧是露天风吕的竹篱笆墙，墙缝里冒出白汽，顺着地面漫开。右侧是几栋更小的木屋和一间卖土产的小店，门口堆着木箱和清酒桶。

街道元素：石板路两侧的石灯笼、立在雪里的木制指示牌、一辆停在坡道边的老式自行车（车座上覆着雪）、门口的雪铲和木屐、屋檐下的灯笼串、一根木质电线杆和电线、排水沟（被雪盖住一半）、坡道上被人踩出的脚印痕迹（不是人物，只是痕迹）、路边的矮竹篱和松树、旅馆侧面的木制招牌、一个冒着热气的露天足汤。

雪要落在屋顶、树枝、灯笼顶、自行车座、石板缝隙上，形成厚薄不一的堆积感。地面积雪与融雪的水光要有对比。

不要人物。气质：安静、治愈、寒冷中有暖意，像冬日旅行时偶遇的一家老旅馆。

美术风格重点：高精细建模、三渲二卡通渲染、清晰轮廓线、细腻简洁的材质、雪的高光与阴影分层、暖色室内光透过纸门与冷蓝雪夜的对比。

动效：持续飘雪、温泉白汽缓慢上升、灯笼轻微摇晃、屋檐冰凌滴水、足汤水面波动、旅馆门内的光偶尔因人影经过而闪动（不出现人影本身）。

整体像一个静止而精致的微缩雪国街角，但带有恰到好处的细微动态。
```

---

## 可调参数

| 变量 | 建议取值 |
|---|---|
| 雪量 | 白天弱、夜晚强；粒子密度 1500–3000 |
| 雪堆 | 用偏移的圆角盒 + 球体叠加，不要均匀铺满 |
| 蒸汽 | 3–5 层半透明面片，缓慢旋转 + 上浮 |
| 冷暖对比 | 室内 2800K 暖橙 / 室外 9000K 冷蓝 |
