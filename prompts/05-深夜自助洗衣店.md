# 05 — 深夜自助洗衣店与投币停车场

```
新建一个文件夹，用代码（Three.js / WebGL，不准使用 Blender、不准用现成模型文件）制作一个深夜自助洗衣店（コインランドリー）与投币停车场小场景。

以第三视角观察，可自由拖拽、旋转、缩放的微缩三维模型 / 小型景观，无任何 UI 界面元素。正方形底座，所有元素搭建其上，构图紧凑、层次清晰，小巧精致、可收藏。

风格：三渲二，日式二次元动画氛围，材质干净，轮廓明确，冷白荧光与暖色点缀交织，色彩柔和。

场景主体：一家独立的小型洗衣店，正面是大面积落地玻璃，店内一排六台滚筒洗衣机 + 两台烘干机，全部在运转，玻璃门里能看到翻滚的衣物色块。店内是冷白色荧光灯，白瓷砖墙、塑料等候椅、折叠桌、杂志架、投币兑换机、洗衣粉自动贩卖机、墙上的使用说明海报、角落的垃圾桶和拖把。店内明亮到有点刺眼，和外面漆黑的夜形成强对比。

店外是投币停车场：地面画着白线车位、编号牌、挡轮、一根挂着「P」标志的柱子、自动收费机（带小屏幕和投币口）、一台停在最里面的旧轿车（车身落满雨水、有反光）、积水坑、排水沟、井盖。

周围：便利店或居酒屋的侧墙、空调外机、电线杆与电线、街灯（冷白光，光锥打在湿地上）、自动贩卖机、靠墙的自行车、堆在角落的蓝色塑料周转箱、贴满贴纸的电箱、远处的护栏和路牌。

地面刚下过雨，柏油是湿的，洗衣店的冷白光和贩卖机的暖光在地面上拉出长长的反光条。

不要人物。气质：孤独、安静、失眠的凌晨三点，机器嗡嗡转着，只有荧光灯陪着。

美术风格重点：高精细建模、三渲二卡通渲染、清晰轮廓线、细腻简洁的材质、冷白荧光与暖色小光源的层次、湿地面强反射。

动效：洗衣机滚筒持续旋转（能看到里面衣物翻滚）、烘干机门内的光缓慢明暗、店内荧光灯轻微闪烁、收费机屏幕数字跳动、地面积水涟漪、屋檐滴水、远处车灯扫过。

整体像一个静止而精致的微缩深夜街角，但带有恰到好处的细微动态。
```

---

## 可调参数

| 变量 | 建议取值 |
|---|---|
| 店内亮度 | 明显高于室外 2–3 档，形成"过曝"感 |
| 滚筒 | 内筒 UV 旋转 + 衣物色块随之滚动 |
| 玻璃 | 反光弱、透明度高，保证能看清机器 |
| 车 | 只做剪影 + 雨水反光，不追求细节 |
