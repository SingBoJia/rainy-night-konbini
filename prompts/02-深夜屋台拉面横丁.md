# 02 — 深夜屋台拉面横丁

```
新建一个文件夹，用代码（Three.js / WebGL，不准使用 Blender、不准用现成模型文件）制作一个深夜屋台拉面横丁小场景。

以第三视角观察整个场景，整体像一个可以自由拖拽、旋转、缩放观看的微缩三维模型 / 小型景观，没有任何 UI 界面元素。地面为一个完整的正方形底座，所有元素都搭建在这个底座上，构图紧凑、层次清晰，整体呈现出小巧、精致、可收藏的模型感。

画面风格为三渲二，强调浓厚的日式二次元动画氛围，材质表现干净，轮廓明确，色彩柔和但富有夜间灯火的层次感。

场景主体是一条只有两米宽的小巷，巷子两侧挤着三四个屋台（路边拉面摊）：红灯笼、暖帘、塑料棚布、折叠凳、冒着白汽的汤锅、塑料菜单牌、啤酒箱、纸巾盒、筷子筒、客人留下的空碗。主摊在最显眼的位置，摊主位置空着（不要人物），但灶台上有一锅正在翻滚的汤，蒸腾的白汽往上飘。摊位内部要亮，暖黄灯光从棚布下面漏出来，照亮摊前的窄巷地面。

巷子两端各有一个转折：一端通向挂着「呑み処」小招牌的岔口，另一端被一堵矮墙和一台自动贩卖机封住。地面上有排水沟、几个积水小坑、散落的烟头、被雨打湿的传单、一块歪掉的井盖。

巷子外围：头顶交错的电线、两盏挂在电线上的裸露灯泡、墙上贴着的手写菜单和褪色海报、空调外机、卷帘门、二层窗户透出的电视蓝光、一小截消防梯、几只堆在角落的啤酒箱和垃圾桶、靠墙停着的一辆破旧自行车、门口挂着的塑料帘。

不要人物。氛围要安静、微醺、有点疲惫的深夜感——像加班回家路上拐进巷子吃一碗面的那一刻。

美术风格重点：高精细建模、三渲二卡通渲染、清晰的轮廓线、细腻但简洁的材质层次、湿润路面反光、暖色灯光与冷色夜巷的强对比。

动效：灯笼轻微摇晃、棚布被风掀起一角、汤锅蒸汽持续上升、灯泡偶发闪烁、屋檐滴水、地面积水涟漪、远处偶尔驶过的车灯扫过墙面。

整体应像一个静止而精致的微缩世界，但带有恰到好处的细微动态。
```

---

## 可调参数

| 变量 | 建议取值 |
|---|---|
| 巷宽 | 2.0 – 2.6 m（越窄越逼仄越有味道） |
| 屋台数量 | 3 – 4 个，主摊占视觉中心偏左 |
| 光源 | 主暖黄 2700K + 电视蓝 8000K 补光 |
| 蒸汽 | 粒子 + 半透明平面叠加，向上缓慢扩散 |
