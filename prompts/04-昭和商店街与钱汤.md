# 04 — 昭和风商店街与钱汤

```
新建一个文件夹，用代码（Three.js / WebGL，不准使用 Blender、不准用现成模型文件）制作一个昭和风商店街与钱汤（公共澡堂）小场景。

以第三视角观察，可自由拖拽、旋转、缩放的微缩三维模型 / 小型景观，无任何 UI 界面元素。正方形底座，所有元素搭建其上，构图紧凑、层次清晰，小巧精致、可收藏。

风格：三渲二，浓厚昭和怀旧感的日式动画氛围，材质干净，轮廓明确，色彩偏暖、略褪色，像旧胶片。

场景主体：一条有顶棚的老商店街，顶棚是半透明波纹板加钢架，灯光从棚顶的灯管洒下来。街两侧依次是：卖糖果和玩具的杂货店（门口摆着玻璃罐和扭蛋机）、肉店（挂着的塑料模型招牌）、理发店（红白蓝三色转灯）、关着的米店（木格子门）、以及街尽头一家有高烟囱的钱汤，烟囱冒着白汽。

钱汤是视觉焦点：正面是唐破风的屋檐、入口挂着「ゆ」的暖帘、门内透出暖光、门口有木制鞋柜和体重秤、墙上贴着价目表和禁止纹身的告示、门口摆着几盆绿植和一辆送牛奶的自行车。

街上的细节：地面是磨得发亮的水磨石与石板、排水沟、几个积水坑、散落的传单、红色的塑料凳、木箱、啤酒箱堆、饮料自动贩卖机（老式，圆角，暖光）、挂着的手写价签、电线、街灯、消防栓、公告栏（贴着商店街地图和祭典海报）、屋檐下的灯串、店门口的塑料帘、一只蹲在钱汤门口的木屐。

不要人物。气质：温暖、怀旧、有点寂寞但有人情味，像夏末傍晚六点的老街区。

美术风格重点：高精细建模、三渲二卡通渲染、清晰轮廓线、细腻简洁的材质、旧漆与磨损的细节、暖黄灯光与傍晚蓝调天空的对比。

动效：理发店转灯旋转、钱汤烟囱冒汽、顶棚灯管偶发闪烁、门口的塑料帘被风吹动、地面积水微光、远处偶尔的电车经过的闪光。

整体像一个静止而精致的微缩老街，但带有恰到好处的细微动态。
```

---

## 可调参数

| 变量 | 建议取值 |
|---|---|
| 顶棚 | 半透明波纹板（alpha 0.3–0.5）+ 钢架线框 |
| 色调 | 整体降饱和 10–15%，高光偏黄，阴影偏褐 |
| 店铺数 | 5 间，钱汤占街尾 1/3 宽度 |
| 转灯 | 圆柱贴图滚动 UV，红白蓝三色循环 |
