# 06 — 海边小镇车站月台

```
新建一个文件夹，用代码（Three.js / WebGL，不准使用 Blender、不准用现成模型文件）制作一个海边小镇的小型车站月台场景。

以第三视角观察，可自由拖拽、旋转、缩放的微缩三维模型 / 小型景观，无任何 UI 界面元素。正方形底座，所有元素搭建其上，构图紧凑、层次清晰，小巧精致、可收藏。

风格：三渲二，日式二次元动画氛围（偏《海街日记》《灌篮高手》那种海边小镇感），材质干净，轮廓明确，色彩柔和通透。

时间设定：黄昏转夜，天空是橙紫渐变，海面还留着最后一点反光。

场景主体：一段单线铁路与一座只有一节的木造月台。月台铺着褪色的地砖，边缘有黄色安全线、盲道、和一块写着站名的木牌（例如「汐見」）。月台上：一张长木椅、一个锈掉的站名牌、一盏老式站灯（已经亮起，暖黄）、一个时刻表框、一台饮料自动贩卖机（暖光，是画面里最亮的点）、一个垃圾桶、一辆靠在柱子上的自行车、柱子上的旧海报和时刻表、月台尽头的小候车室（木造、玻璃窗、里面有一张长椅和一盏灯）。

轨道：两条铁轨、枕木、碎石、信号机（红绿小灯）、轨道旁的杂草、一个平交道口（黄黑相间的栏杆、闪灯、警示牌）。

背景：月台后方是几栋低矮的海边民宅（瓦顶、晾衣杆、阳台、空调外机），再远处是海（用色块和反光表现），海面上有一点点渔船灯光。月台另一侧是坡道和矮墙。

细节：地面上的落叶、几张被风吹来的纸、月台缝隙里的小草、栏杆上的锈迹、贩卖机旁边的回收箱、墙上的涂鸦、电线杆与电线、远处隧道口。

不要人物。气质：安静、微凉、带着一点离别的怅然，像动画里主角等末班车的那一幕。

美术风格重点：高精细建模、三渲二卡通渲染、清晰轮廓线、细腻简洁的材质、黄昏天空的渐变与暖灯的层次、铁轨的高光。

动效：站灯轻微闪烁、贩卖机的灯呼吸、信号机红绿变化、海面波纹缓慢流动、远处云缓慢移动、旗帜或晾衣杆上的布被风吹动、地上的落叶偶尔被卷起。

整体像一个静止而精致的微缩海边车站，但带有恰到好处的细微动态。
```

---

## 可调参数

| 变量 | 建议取值 |
|---|---|
| 天空 | 橙 → 紫 → 深蓝三段渐变，地平线附近加暖光晕 |
| 海面 | 低多边形 + 顶点波动，或纯色块 + 反射条纹 |
| 铁路 | 单线即可，轨距 1067mm 视觉比例 |
| 光源 | 站灯暖黄 3000K 为主，天空冷紫为辅 |
