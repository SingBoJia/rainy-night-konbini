# 08 — 通用模板：可复用骨架 + 模块拼装

> 把"微缩模型"类需求拆成 **骨架段** + **模块段**，任意组合就能生成新场景。
> 直接复制下面模板，替换 `{{ }}` 里的内容即可。

---

## 模板 A：标准微缩模型骨架

```
新建一个文件夹，用代码（{{ 技术栈，如 Three.js / WebGL }}，不准使用 Blender、不准用现成模型文件）制作一个{{ 场景名 }}小场景。

以第三视角观察，可自由拖拽、旋转、缩放的微缩三维模型 / 小型景观，无任何 UI 界面元素。正方形底座，所有元素搭建其上，构图紧凑、层次清晰，小巧精致、可收藏。

风格：三渲二，{{ 风格关键词 }}，材质干净，轮廓明确，{{ 色彩倾向 }}。

场景主体：{{ 主体建筑 / 主体物件 }}，位于底座视觉中心。{{ 主体描述 3–5 句 }}

周边元素：{{ 从模块库挑选 8–12 项 }}。

不要人物。气质：{{ 情绪关键词 }}。

美术风格重点：高精细建模、三渲二卡通渲染、清晰轮廓线、细腻简洁的材质、{{ 光影关键词 }}。

动效：{{ 从动效库挑选 5–8 项 }}。

整体像一个静止而精致的微缩{{ 场景类型 }}，但带有恰到好处的细微动态。
```

## 模板 C：纯风格探索版

```
用 Three.js 做一个微缩场景，主题自选，但必须满足：
1. 正方形底座，所有元素在底座上，可自由旋转缩放；
2. 三渲二渲染，有清晰轮廓线（屏幕空间描边）与色阶化光照；
3. 主色 {{ 主色 }}，辅色 {{ 辅色 }}，只允许一个高饱和强调色；
4. 至少 30 个独立几何元素，其中 5 个以上是"没人注意但存在"的细节；
5. 3 个以上循环动效；
6. 无 UI，无人物。
```
