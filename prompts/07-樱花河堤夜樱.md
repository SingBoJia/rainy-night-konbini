# 07 — 樱花河堤夜樱与屋台

```
新建一个文件夹，用代码（Three.js / WebGL，不准使用 Blender、不准用现成模型文件）制作一个樱花季河堤夜樱与屋台小场景。

以第三视角观察，可自由拖拽、旋转、缩放的微缩三维模型 / 小型景观，无任何 UI 界面元素。正方形底座，所有元素搭建其上，构图紧凑、层次清晰，小巧精致、可收藏。

风格：三渲二，日式二次元动画氛围，材质干净，轮廓明确，粉与蓝的柔和对比，夜晚但有暖光。

场景主体：一段河堤，堤上种着一排盛开的樱花树（树冠用色块化的团块表现，花瓣有层次），树下挂着红色的提灯串（ぼんぼり），灯光把花瓣照成暖粉色。河堤的石阶向下通向河边的散步道。

河堤上摆着两三个小摊：卖章鱼烧的、卖苹果糖的、卖捞金鱼的（水槽里有几条橙红色的小鱼色块）。摊位有塑料棚布、暖帘、招牌旗、煤气罐、折叠桌、塑料凳、纸灯笼。

河面上：几艘小船、水面的灯光倒影、被风吹落的花瓣漂在水上、一座小桥（木造或石造）横跨画面一侧。

其他元素：护栏、石灯笼、长椅、垃圾桶、自行车、公告栏（贴着「夜桜祭」海报）、路牌、电线杆、远处的对岸建筑剪影和窗户灯光、堤下的草地和野餐布（空的）。

地面：石板路、泥土、积水、掉落的花瓣铺了一地。

不要人物。气质：温柔、微醺、热闹里带一点空落，像祭典散场后独自走回家的那一段路。

美术风格重点：高精细建模、三渲二卡通渲染、清晰轮廓线、细腻简洁的材质、樱花粉与夜蓝的对比、灯笼暖光在花瓣与水面上的层次。

动效：持续飘落的花瓣、水面波纹与花瓣漂流、提灯轻微摇晃、摊位灯笼的暖光呼吸、河水缓慢流动、摊位棚布被风吹动、远处偶尔的烟花闪光（很淡）。

整体像一个静止而精致的微缩夜樱河堤，但带有恰到好处的细微动态。
```

---

## 可调参数

| 变量 | 建议取值 |
|---|---|
| 樱花树 | 树冠用 8–12 个不同大小的球体拼，颜色 3 档粉色 |
| 花瓣 | 粒子 800–1500，带旋转 + 左右飘移 |
| 提灯 | 圆柱 + 顶底盖，暖光色 + 轻微自发光 |
| 水面 | 反射 + 波纹法线扰动，花瓣用平面贴图漂移 |
